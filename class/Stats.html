Description

Stats is a service that provides real-time performance information about the current running game instance. Its primary purpose is to provide an end point to measure where resources are being consumed, as well as how much memory is being consumed overall.

The service also stores a tree of StatsItem objects which can have their values read by plugins.

GetTotalMemoryUsageMb
CreatorHub

Parameters (0)
No parameters.
Returns (1)
float

Returns the total amount of memory being consumed by the current game session, in megabytes. If MemoryTrackingEnabled is false, calling GetTotalMemoryUsageMb will return 0 and emit a warning to the console.

This method gets memory usage from the operating system, which may exclude memory that has been paged out to disk. As such, the return value tends to differ significantly from the sum of usage for all DeveloperMemoryTags. The return value should be very similar to memory usage for Roblox in the Windows Task Manager or macOS Activity Monitor.

MemoryTrackingEnabled
CreatorHub

TypeDefault
bool

If MemoryTrackingEnabled returns false, any API that returns category-based memory usage e.g. GetMemoryUsageMbForTag or GetTotalMemoryUsageMb will return 0 and emit a warning. Therefore, usage of category-based memory usage API should be conditional on MemoryTrackingEnabled returning true. The value of MemoryTrackingEnabled will not change from one experience to the next. It will only potentially change after restarting the Roblox client application.

This property is not replicated. Its interface does not cross the network boundary.
This property is read-only. Its value can be read, but it cannot be modified.
